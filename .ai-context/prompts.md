# Project Task Prompts

1. Set up TypeScript Node.js project structure
   Prompt: Initialize a TypeScript project with Node.js, configure tsconfig, and set up src, tests, and docs folders.

2. Implement user & access management module
   Prompt: Develop authentication and role-based access control (Writer/Approver) using SSO integration and session management.

3. Integrate SharePoint & knowledge ingestion
   Prompt: Connect to SharePoint repositories, extract and index Word/PDF documents, normalize and segment content for semantic search.

4. Add external data integration module
   Prompt: Implement secure API-based integration with approved external sources, validate and normalize data, and index for unified search.

5. Develop knowledge retrieval & semantic search
   Prompt: Build natural language query processing, semantic similarity search, and contextual content ranking for document retrieval.

6. Build AI response generation module
   Prompt: Create context-based prompt construction, grounded response generation, and answer formatting for chat-based responses.

7. Create user interaction & offline utilisation
   Prompt: Design chat-based response viewing, manual copy functionality, multi-query support, and session-based query continuity.

8. Write unit and integration tests
   Prompt: Develop comprehensive unit and integration tests for all modules, covering positive, negative, and edge cases.

9. Document architecture and workflows
   Prompt: Write clear documentation for system architecture, module workflows, and integration points. Include engagement responsibilities, technology stack, release management, ownership, and change management.

10. Prepare technical documentation and handover
    Prompt: Compile technical documentation, conduct knowledge transfer, and prepare for project handover. Ensure transition support, confidentiality, and environment handover as per BRD.
