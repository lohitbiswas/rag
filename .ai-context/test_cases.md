# Test Cases

Master list of test scenarios.

# QA Execution Process

1. Analyse requirement documents
2. Prepare detailed test plan (manual/automated)
3. Write comprehensive test cases (positive, negative, edge, functional, non-functional)
4. Release build for testing
5. Execute test cases, log results, document defects
6. Verify closed issues, retest, regression testing
7. Test closure and stakeholder sign-off

# Example Test Scenarios

- Authentication and access control
- SharePoint document ingestion and indexing
- API integration and data validation
- Natural language query processing
- Semantic search and content retrieval
- AI response generation and formatting
- User interaction and offline utilisation
